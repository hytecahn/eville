수정 사항 Changelog

## 0.0.12

- 별도 감시 프로세스가 이벤트 루프의 heartbeat를 감시합니다. 정지 감지 시 스택을 기록하고 통신 프로세스를 재생성합니다. 기본 감지 시간은 120초입니다.
- MQTT/소켓 장애, 태스크 예외 및 큐 초과 시 기존 태스크와 연결을 정리한 후 새 세션과 MQTT 클라이언트를 생성합니다. 반복 실패는 최대 60초까지 재시도 간격을 늘립니다.
- 소켓 connect/recv/send를 비동기로 바꾸고 EOF를 처리했습니다. Telnet 리셋은 유한한 시간 제한을 가진 별도 스레드로 옮기고 실제 프롬프트 수신을 확인합니다.
- 수신 큐(1000), 명령 큐(100)와 한 번의 처리량을 제한했습니다. 소켓 수신 메시지가 같은 객체를 공유하던 문제를 수정했습니다.
- MQTT 재연결 후 Discovery/상태를 다시 발행하며 발행 실패를 무시하지 않습니다. 제어용 retained 메시지와 잘못된 명령/온도/패킷을 거부합니다.
- 경과 시간 계산에 monotonic clock을 적용했습니다. 명령 수신이나 손상된 데이터가 정상 상태로 판정되는 문제를 줄였습니다.
- SIGTERM 정상 종료 및 exec 진입점을 추가하고 Paho 2.1.0의 Callback API v2를 사용합니다.
- 초기 상태가 없는 명령의 DEBUG 로그 예외, 난방 OFF 상태 변수, 콘센트 자동모드 값 및 불완전 패킷 잔여 버퍼 처리를 수정했습니다.
- `mqtt_port`(1883), `watchdog_timeout`(120초) 옵션을 추가했습니다. 기존 옵션에도 기본값을 적용합니다.

## 0.0.11

- `/share`에 90일간 보존되는 일 단위 회전 진단 로그를 추가했습니다.
- MQTT/EW11 수신 시각, Queue 크기와 자동 복구 횟수를 10분마다 기록합니다.
- asyncio, background task, thread 및 main process의 전체 traceback을 영구 로그에 남깁니다.
- Paho MQTT 내부 경고와 오류를 기록하여 재연결 실패 원인을 확인할 수 있게 했습니다.

## 0.0.10

- MQTT 연결 해제 후 2분 안에 재연결되지 않으면 통신 루프를 자동 재생성하도록 watchdog을 추가했습니다.
- 백그라운드 asyncio task의 예외를 감지하여 조용히 감시/수신 루프가 중단되는 문제를 방지했습니다.
- Socket 재연결 시 잘못된 함수 인자로 task가 종료되던 문제를 수정했습니다.
- EW11 Telnet 재시작과 상태 확인에 timeout을 적용하여 장애 복구 루프 자체가 멈추지 않도록 했습니다.
